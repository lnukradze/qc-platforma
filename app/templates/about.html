საწარმოო გაშვებისთვის საჭიროა (IT)

  • სერვერი: Linux VM (≈4 vCPU, 8 GB RAM, 100 GB) ან Windows Server; Docker სასურველია
  • PostgreSQL 16 (+PostGIS) · ღამის ბექაპი + დროის წერტილზე აღდგენა
  • დომენი *.napr.gov.ge + HTTPS სერტიფიკატი (Google-ის მოთხოვნა)
  • გარედან წვდომა (ველი — ტელეფონი/პლანშეტი) + სერვერიდან Google-ზე გასვლა
  • Google Cloud პროექტი სააგენტოს სახელზე (OAuth client)
  • REGFIELDALL GDB / საველე ბაზის read-only წვდომა სერვერიდან
  • REDI · SLR · WFS — read-only API ან view (Pre-QC-ისთვის)
