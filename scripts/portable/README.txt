NAPR — ხარისხის კონტროლის ერთიანი პლატფორმა (პროტოტიპი) — პორტატული ვერსია
==========================================================================

გაშვება
  1. ZIP ამოაარქივეთ: მარჯვენა ღილაკი → „Extract All…“ (ZIP-ის შიგნიდან პირდაპირ არ გაუშვათ).
  2. ამოარქივებულ საქაღალდეში ორჯერ დააწკაპუნეთ START.bat-ზე.
     გაიხსნება შავი ფანჯარა და ბრაუზერი: http://127.0.0.1:8200
  3. შესვლა — აირჩიეთ მომხმარებელი სიიდან (დემო რეჟიმი). როლი ზედა ზოლში იცვლება.
  4. გასაჩერებლად — დახურეთ შავი ფანჯარა.

რა არ სჭირდება
  • ინსტალაცია და ადმინისტრატორის უფლება — Python საქაღალდეშივეა (runtime);
  • ინტერნეტი — ყველაფერი ამ კომპიუტერზე მუშაობს.

რა არ ხდება
  • სხვა კომპიუტერიდან არ იხსნება (მხოლოდ 127.0.0.1);
  • მეილი არ იგზავნება; Google-ით შესვლა გამორთულია;
  • განაწილების გაშვება არ მუშაობს — წყარო ბაზა ამ პაკეტს არ მოჰყვება.

თუ Windows გაფრთხილებას აჩვენებს
  „Windows protected your PC“ → „More info“ → „Run anyway“.
  ან: ZIP-ზე მარჯვენა ღილაკი → Properties → „Unblock“ → OK, შემდეგ ამოაარქივეთ თავიდან.
