## 2. კომპონენტები

```
ბრაუზერი / ტელეფონი / პლანშეტი
        │  HTTPS (საწარმოოში), სესიის cookie
        ▼
FastAPI ვებ-აპლიკაცია ─── Jinja2 გვერდები + HTMX + ECharts/Leaflet
   │   routes/        გვერდები, JSON API (/api, /docs), Google OIDC (/auth/google)
   │   workflow.py    სამუშაო პროცესი (state machine) + ისტორია
   │   scope.py       ხილვადობა — ყოველი მოთხოვნა სერვერზე იფილტრება
   │   services/      directory (ვინ ვისი გუნდიდანაა) · distribution · sporadic ·
   │                  legacy_import · stats · notify (მეილი) · codes (rules.gs)
   ▼
SQLAlchemy 2 ─── SQLite (პროტოტიპი) / PostgreSQL (საწარმოო)
   ▲  read-only
REGFIELDALL (Distributor-ის ასლი) · სპორადულის xlsx · Google ცხრილები (GET) · QC სამუშაო.xlsx
```

საწარმოოში ემატება:
- reverse proxy (TLS);
- ფონური worker (იმპორტი, ღამის ამოცანები);
- ბექაპი და მონიტორინგი;
- SMTP relay;
- Pre-QC Validator-ის სერვისი.

## 5. სამუშაო პროცესი (state machine)

მდგომარეობები:
1. `pending` (გასავლელი)
2. `awaiting_field` (ველზე)
3. `awaiting_manager` („არ ვეთანხმები“, მენეჯერის დადასტურება)
4. `awaiting_qcm` (არ დათანხმებული, QC მენეჯერთან)
5. `returned_to_manager` (დაბრუნებულია მენეჯერთან)
6. `awaiting_qc` (QC-ის გადამოწმება)
7. `closed`

### 5.1 CC პრინციპი

კონტროლის მხრიდან დაბრუნებისას (ოპერატორის „არ გასწორდა“ და QC მენეჯერის „ხარვეზი რჩება“) ჩანს მონიშვნა **„საჭიროა საველე მენეჯერის ჩართვა“**:
- **მოუნიშნავი** (ნაგულისხმევი): შემთხვევა ამზომველებს უბრუნდება, მენეჯერი ხედავს (CC) და, თუ მონიშნულია „✉“, მეილსაც იღებს.
- **მონიშნული**: პასუხობს მხოლოდ მენეჯერი.

### 5.2 ორი ამზომველი ერთდროულად

- ბარათზე და სიაში ყვითელი, ნელა მოციმციმე ნიშანი ჩანს: „ახლა ხსნის: X“.
- ძალაში რჩება პირველად გაგზავნილი პასუხი (`version`-ის შემოწმება).
- მეორე ამზომველი ხედავს, ვინ და როდის უპასუხა, და კომენტარის დამატება შეუძლია.

## 10. Pre-QC (გეგმა)

- **გრაფიკი:** მივლინების მე-3 დღიდან, დღე N ამოწმებს დღე N−2-ის ოქმებს. დაყოვნება პარამეტრია.
- **ხილვადობა:** მხოლოდ საველე მენეჯერი და ამზომველი. სხვას არავის, ადმინის ჩათვლით.
- **ახლა:** 216 ფიქსირებული შემოწმება სადემონსტრაციო გუნდზე.
- **ინტეგრაცია:** შეყვანის ფორმატი (HTML/TXT ოქმი თუ API) დასაზუსტებელია, ამიტომ Validator ცალკე „ადაპტერით“ ჩაერთვება.
- **შეთავაზებული კონტრაქტი:** `POST /api/preqc/results` (API გასაღებით):
  - `protocol_number, cadcode, checked_on, score, status`;
  - `findings[{code, official_code, severity, title, message, recommendation}]`.

## 14. პროტოტიპის შეზღუდვები

- Google OIDC ჩაშენებულია, მაგრამ client ID-ის გარეშე გამორთულია.
- SQLite ერთი პროცესისთვისაა. გადახედვები და presence საწარმოოში PostgreSQL-ში (ან Redis-ში) უნდა გადავიდეს რამდენიმე worker-ისთვის.
- მეილი რეალურად არ იგზავნება, სანამ SMTP არ იქნება.
- სპორადულის ფილტრის წესები დასაზუსტებელია.
- Pre-QC — დემო.
- სტატისტიკის გვერდი SQLite-ზე 2–3 წამში იტვირთება (44 ათასი შემთხვევა). PostgreSQL-ზე და ინდექსებით ეს უნდა შემცირდეს.
