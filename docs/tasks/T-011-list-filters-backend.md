**შედის:**

   ოთხივე route მას იყენებს; ძველი `_filters` / `_d` (`routes/qc.py`, `routes/field.py`) იშლება.
2. წესები:
   - **თარიღი** — `QcItem.drawing_date` (ნახაზის შეტანა) ყველა სიაში. `date_from` ჩათვლით (00:00-დან), `date_to` — **არა** (00:00-მდე):

   - **ოპერატორი** — id; **ველის როლებისთვის იგნორდება და სია ცარიელია** (კონტროლი ანონიმურია).
   - **სტატუსი** (`verdict`) — QC სიის „გასავლელში“ იგნორდება (`flt.show_status = False`).
   - **ველის სტატუსი** (`response`), **სახე** (`kind`), **ოქმის#** (`protocol`), **საკ. კოდი** (`cad`) — როგორც ახლა.

   - ოპერატორის „გასავლელი“ — ძველი შეზღუდვა რჩება (`restricted_filters`: მხოლოდ ოქმის# და საკ. კოდი), `flt.limited = True`.
   - **ველის სია** (ლუკა, 2026-10-27, T-007 Q-02): საბოლოოდ დადასტურებული (`closed`) ოქმი ნაგულისხმევ სიაში არ ჩანს; ჩანს, როცა ფილტრი
     (`state=closed` ან სტატუსი / თარიღი) ან ძებნა (ოქმის# / საკ. კოდი) მითითებულია. რომელი ოქმი ჩანს ველს საერთოდ — T-021 (`scope.field_visible`).

   QC როლები, ადმინი, კოორდინატორი — ნებისმიერი მენეჯერი; საველე მენეჯერი — მხოლოდ საკუთარი გუნდი; სხვა — `[]`. `scope`-ის წესით, CSRF არ სჭირდება (GET).

### განხორციელების ნაბიჯები

1. შექმენი `app/services/listfilter.py`: პარამეტრების წაკითხვა/ნორმალიზაცია, SQLAlchemy `select`-ზე გამოყენება და არჩევანის სიების მომზადება.
   გამოიყენე `/qc`, `/field`, `/qc/disagreements`, `/checked` route-ებში; ჩანაცვლებული `_filters` / `_d` წაშალე.
   შეინარჩუნე თითოეული სიის ავტორიზაცია, საწყისი ერთობლიობა, ჩანართები და დალაგება. ფილტრები დაემატოს უკვე scope-ით შეზღუდულ მოთხოვნას.
2. თარიღი ყველგან `QcItem.drawing_date`: `date_from >=` მითითებული დღის 00:00; `date_to <` მითითებული დღის 00:00.
   თანაბარი ან შებრუნებული საზღვრები — 0 შედეგი და `empty_range=True`; ერთი საზღვარი — ცალმხრივი პირობა.
   არ გამოიყენო `sent_at` ან დღის ბოლომდე ჩათვლის ძველი წესი. ბრიფში განუსაზღვრელი შეყვანისთვის ახალი HTTP კონტრაქტი არ მოიგონო.
3. ზონა დაშალე მძიმით/ჰარით, თითოეული `zfill(2)`, გამოიყენე `IN`. სექტორი ზონის გარეშე იგნორირდება;

   QC როლები/admin/coordinator — ნებისმიერი მენეჯერი; საველე მენეჯერი — საკუთარი გუნდი, სხვისაზე `[]`; სხვა როლები — `[]`.
