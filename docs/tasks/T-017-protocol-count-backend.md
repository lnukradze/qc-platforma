   ერთი ფუნქცია `source.py`-ში სამივე გზისთვის (სისტემური, სპორადული, backfill); გადახედვის `protocol_count`-იც იმავე წესით
   (ახლა სისტემურ ოქმებს გამორიცხავს). კანდიდატის წესი ამით არ იცვლება.
