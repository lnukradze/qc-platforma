## 1. ბრიფი — lead

**მიზანი (P0):** წესი — „ერთ კოდზე ერთი პასუხი; პირველი პასუხი ითვლება“ (`docs/OPEN_QUESTIONS.md`, „ორი ამზომველი ერთად“). T-009-მა (E-06) დაადასტურა,
რომ ორი ერთდროული პასუხი **ორივე** ინახება: ვერსიის შემოწმება (`workflow.py:235`) წაკითხვასა და ჩაწერას შორის ატომური არ არის.
ერთიანი სურათი — `docs/reports/STAGE-1-SUMMARY.md`, P0-2.

**შედის:**
1. **ატომური ვერსია** — ყოველი ქმედება, რომელიც მდგომარეობას / სტატუსს ცვლის: ჩაწერა ერთი `UPDATE qc_items … WHERE id = :id AND version = :v` (ან SQLAlchemy
   `version_id_col`), შეცვლილი მწკრივი 0 → `ConflictError` (არსებული შეტყობინებით „ამ ოქმზე პასუხი უკვე გაგზავნა …“). SQLite-ზეც და PostgreSQL-ზეც.
   `version` ფორმაში **სავალდებულოა** მდგომარეობის შემცვლელ ქმედებებზე (T-010, S-09).
2. **კომენტარი** — B-11: ორჯერ დაჭერა / ორი ჩანართი → ერთი კომენტარი და ერთი მეილი (ერთჯერადი token ფორმაში ან „იგივე ტექსტი + ავტორი ბოლო 60 წმ-ში“ → არ იქმნება).
   B-12: კომენტარი და QC მენეჯერის შეფასება `version`-ს **არ** ზრდის (კონფლიქტი მხოლოდ მდგომარეობის / სტატუსის ცვლილებაზე).
3. რეგრესიის ტესტი **ნამდვილი პარალელით** (ორი ნაკადი / ორი სესია, ერთი საწყისი `version`, ერთდროული POST) — 20 გამეორება, ყოველთვის ზუსტად ერთი წარმატება.

**არ შედის:** შაბლონები (ui-ს ფორმის ველი, თუ token სჭირდება — „სხვა როლებისგან სჭირდება“ commit-ში); სხვა სამუშაო წესები — T-021.

**ფაილები (ზონა):** `app/workflow.py`, `app/routes/items.py`, `app/services/notify.py`, `tests/test_concurrency.py` (ახალი — ნებადართული გამონაკლისი).
`models.py`-ში ცვლილება თუ სჭირდება (მაგ. `version_id_col`) — შეჩერდი და lead-ს უთხარი.

**კონტრაქტი (backend ↔ ui):** თუ token — `<input type="hidden" name="once" value="{{ once }}">` კომენტარის ფორმაში (`once` — ბარათის კონტექსტში).

**დასრულების პირობა** (ტესტირებადი):
1. `tests/test_concurrency.py`: 20 / 20 — ორი ერთდროული `field_respond` ერთ ვერსიაზე → ერთი წარმატება, ერთი `ConflictError`; ერთი `field_responded` მოვლენა.
2. `version`-ის გარეშე მდგომარეობის შემცვლელი POST → უარი.
3. კომენტარი ორჯერ ზედიზედ (ერთი token / ერთი ტექსტი) → 1 მოვლენა, 1 მეილი; კომენტარის შემდეგ სხვა მომხმარებლის ღია ფორმა „სხვამ შეცვალა“-ს **არ** იღებს.
4. T-007-ის B-11 / B-12 ფრაგმენტები ახლა ჩავარდება (ხარვეზი დაიხურა) — ტესტებში შებრუნებული სახით.
5. `pytest -q` გადის; `smoke_pages.py` დემო ბაზაზე — 0 შეცდომა.

**ჩაბარებისას შევამოწმებ:** პარალელური ტესტი ჩემთანაც 20 / 20; ისტორია — ერთი პასუხი.

**lead-ის გადაწყვეტილებები qa-ს კითხვებზე (2026-10-27):**
1. **ვერსიის ფარგლები** — `workflow.apply()`-ის **ყველა** მოქმედება, გარდა `comment`-ისა და `review`-ისა: `version` სავალდებულოა და მოწმდება ატომურად.
   მეთოდი: მოქმედების დასაწყისში `UPDATE qc_items SET version = version + 1 WHERE id = :id AND version = :v`; შეცვლილი მწკრივი 0 → `ConflictError`.
   შემდეგ ORM-ის `item.version` ხელმეორედ არ იზრდება. `version_id_col` არ გამოიყენება.
   `comment` და `review` ვერსიას არც ამოწმებს, არც ზრდის (B-12).
2. **დუბლიკატი** — ერთჯერადი token. ბარათის კონტექსტში `once` (`secrets.token_urlsafe(24)`), კომენტარის ფორმაში `<input type="hidden" name="once">` (ui, T-016 — „სხვა როლებისგან სჭირდება“).
   POST-ზე token იწერება `FormToken`-ში (`app/models.py`, ცხრილი `form_tokens` — lead-მა დაამატა), კომენტართან ერთ ტრანზაქციაში.
   PRIMARY KEY-ის დარღვევა → rollback: მოვლენა და მეილი არ იქმნება; ბარათზე დაბრუნება შეტყობინებით „კომენტარი უკვე დამატებულია“, შეცდომის გარეშე.
   token-ის გარეშე კომენტარი → უარი „განაახლეთ გვერდი“. „იგივე ტექსტი 60 წმ-ში“ წესი **არ** გამოიყენება.
3. **მხოლოდ ფოტო** — კომენტარი ფაილით, ტექსტის გარეშე, დასაშვებია (როგორც ახლა). იგივე token-ით დაცული; ფაილს მხოლოდ QC ტვირთავს (უცვლელი).
4. **ერთდროული გადაწყვეტილებები და შეფასებები** — QC მენეჯერის გადაწყვეტილება (`qcm_*`) და ყველა სხვა მდგომარეობის ცვლილება — პირველი ითვლება (ვერსია).
   შეფასება (`review`) — ბოლო ითვლება, ორივე `qc_reviewed` ისტორიაშია; ერთდროული პირველი `QcReview` (PK `item_id`) → `IntegrityError` → განახლებად გადაკეთდეს, **500 არა**.
5. **`/qc/bulk-send`** — იშლება აქ, T-019-ში (`routes/qc.py`-ში მხოლოდ ეს route და მისი ტესტები — ნებადართული გამონაკლისი), რადგან `version`-ს არ აგზავნის. T-011-დან ეს პუნქტი მოიხსნა.
