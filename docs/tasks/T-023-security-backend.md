## 1. ბრიფი — lead

**მიზანი:** T-010-ის უსაფრთხოების აღმოჩენები (`docs/reports/T-010-security-contract.md`, S-01 – S-13) და T-007 / T-008-ის მონათესავე რისკები.
ლუკას გადაწყვეტილება (T-008 Q-03): ტესტირებისთვის შესვლის სია რჩება; საწარმოოში — REDI ან Google, მხოლოდ რეგისტრირებული ელფოსტით, გარედან არანაირი სია და სახელი.

**შედის:**
1. **საწარმოოს რეჟიმი** — S-01: `QCP_DEMO_LOGIN`-ის ნაგულისხმევი `0`; `run.bat` / `run_local.py` / `agent.ps1` / `serve_lan.py` რთავს `1`-ს;
   გაშვებისას გაფრთხილება, თუ host ≠ 127.0.0.1 და დემო ჩართულია PIN-ის გარეშე. დემო გამორთულია → შესვლის გვერდზე სია **და** „არ არის რეგისტრირებული“-ში სახელები — არა
   (T-008 Q-03; `login.html`-ის ტექსტი — ui: „სხვა როლებისგან სჭირდება“). S-06: `secure` cookie — `QCP_BASE_URL` https-ით; `--proxy-headers`.
   S-08: `QCP_API_DOCS=0` → `/docs`, `/redoc`, `/openapi.json` გამორთული (საწარმოოში ნაგულისხმევი). `config.py`-ის ცვლილებები — lead-ს მიაწოდე (ის ცვლის).
2. **უსაფრთხო გადამისამართება** — S-02: ერთი `safe_path()` (`/`-ით იწყება; არა `//`, `/\`, სქემა) — `auth.py:47`, `:80`, `google_auth.py:82`, `items.py:94` / `:154` / `:187`, `reports` (T-013).
3. **API-ს ზღვრები** — S-04: `limit` 1–200, `offset` ≥ 0.
4. **PIN** — S-05: მცდელობების მთვლელი IP-ზე (10 → 5 წთ ბლოკი).
5. **`/role`** — S-10: სესია `read_session()`-ით; არ არის → `LoginRequired`.
6. **Excel** — S-11: `=`, `+`, `-`, `@`-ით დაწყებული ტექსტი — ფორმულად არა (ყველა ექსპორტი, T-013-ის ჩათვლით).
7. **ფაილები** — S-12: ზომა ნაწილ-ნაწილ წაკითხვისას; B-16: ტიპი შიგთავსით (JPEG / PNG / WEBP / GIF / PDF ხელმოწერა).
8. **CSRF** — S-13 / U-37: `Origin` ↔ `QCP_BASE_URL`, თუ მითითებულია; ორივე სათაურის არქონისას POST — უარი.
9. **ძველი იმპორტი** — B-17: `import_control` მხოლოდ ცარიელ ბაზაზე (სხვა შემთხვევაში — უარი). **სპორადული** — B-18: რაოდენობიანი და ურაოდენობო ოპერატორები ერთად → გაფრთხილება გადახედვაში.

**არ შედის:** CSP (S-07 — ეტაპი 3, inline სკრიპტების გატანის შემდეგ); `config.py` (lead); შაბლონები.
