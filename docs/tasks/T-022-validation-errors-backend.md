## 1. ბრიფი — lead

**მიზანი:** სერვერი ყოველ არასწორ შეყვანას თავად ამოწმებს და გასაგებ ქართულ შეტყობინებას აბრუნებს; 500 / 422 JSON HTML გვერდზე — არა.
წყარო და გამეორება — `docs/reports/T-007-backend-audit.md` (B-01, B-06, B-09, B-10, B-15), `T-008-ui-audit.md` (U-10, U-34, U-36).

**შედის:**
1. **ადრესატი და ხალხი** — B-01: `reassign` → მხოლოდ აქტიური `qc_operator`; B-09: `assign_manager` → მხოლოდ აქტიური `field_manager`;
   B-10: კოდი → მხოლოდ აქტიური `DefectCode`; ამზომველი → `surveyor` / `field_manager` როლით. არასწორი / არარიცხვი id → `WorkflowError`, არა 500.
2. **ფორმების ველები** — B-06: ერთი დამხმარე (რიცხვი / თარიღი / არსებული id / ფაილის ტიპი) → `redirect(err=…)`: განაწილების `preview` / `confirm`,
   სპორადულის `lookback_days` და არა-xlsx ფაილი, ადმინის პარამეტრები, მომხმარებლის შექმნა არსებული ელფოსტით (`IntegrityError`), `surveyors=999999`.
3. **შეცდომის გვერდები** — B-15: `RequestValidationError` და `Exception` handler-ები — HTML გვერდზე `error.html` (ქართულად), `/api/`-ზე — JSON; 500 — ლოგში.
   starlette-ის `HTTPException`-იც (404 როუტინგიდან) იგივე handler-ით.
4. **HTMX და ვადაგასული სესია** — U-10 (backend ნაწილი): HTMX მოთხოვნაზე (`HX-Request`) `LoginRequired` → `HX-Redirect: /login?next=…` (და არა 303 → შესვლის გვერდი ცხრილში);
   U-09-ისთვის — `HX-History-Restore-Request`-ზე სრული გვერდი (ui-ს ნაწილი — T-026).
5. **შეტყობინება URL-იდან** — U-34: `?ok=` / `?err=` — თავისუფალი ტექსტის ნაცვლად **გასაღები** (`?msg=sent`) და ტექსტი სერვერის ლექსიკონიდან;
   ცნობილი გასაღების გარეშე — არაფერი. (შაბლონი `base.html` — ui: „სხვა როლებისგან სჭირდება“, თუ ცვლადის სახელი იცვლება.)
6. **დემო შესვლა** — U-36: შესვლის გვერდის ჯგუფებში „სამსახურის უფროსიც“.
7. **სიების ფილტრის id** (T-011-ის ჩაბარება, ლუკა 2026-10-28 — **production-ის ბლოკერი**): `manager`, `surveyor`, `operator` —
   `/qc`, `/field`, `/checked`, `/qc/disagreements` და `GET /api/filters/surveyors?manager=`. id — მხოლოდ ASCII ციფრები, მაქსიმუმ 9 ნიშანი
   (PostgreSQL `integer`-ში ეტევა); სხვა: `manager` / `surveyor` → სახელით ძებნა (`LIKE`), `operator` → იგნორი, API → `[]`. ერთი დამხმარე — `app/services/listfilter.py`.
   ახლა 20+ ციფრი ან „²“ → 500 (SQLite); PostgreSQL-ზე — უკვე 10+ ციფრი (11-ნიშნა პირადი ნომერი ამზომველის ველში).

**არ შედის:** უსაფრთხოების სხვა პუნქტები (T-023); შაბლონები.

**ფაილები (ზონა):** `app/workflow.py`, `app/routes/*.py`, `app/main.py`, `app/security.py`, `app/services/sporadic.py`, `app/services/listfilter.py`, `tests/test_validation.py` (ახალი — ნებადართული გამონაკლისი).

**კონტრაქტი (backend ↔ ui):** `render()`-ის `ok` / `err` — უკვე ტექსტი (სერვერის ლექსიკონიდან), შაბლონი უცვლელი რჩება. HTMX: `HX-Redirect` სათაური.

**დასრულების პირობა** (ტესტირებადი):
1. T-007-ის B-01, B-06, B-09, B-10 ფრაგმენტები — შებრუნებული (უარი, 500 არა); B-06-ის რვავე შემთხვევა → 303 `err`-ით ან 4xx, **არცერთი 500**.
