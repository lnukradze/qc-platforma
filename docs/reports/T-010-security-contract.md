## მოკლედ

- პროტოტიპის უსაფრთხოების საფუძველი კარგია: ყოველ POST-ს CSRF აქვს, ყოველ route-ს — როლის შემოწმება, ოქმი და ფაილი `scope.py`-ს გადის,
  ქმედება სერვერზე მოწმდება (როლი + მდგომარეობა), XSS და SQL injection ვერ ვიპოვე, git-ში საიდუმლო ან მონაცემი არასოდეს მოხვედრილა.
- **საწარმოოში გაშვებამდე აუცილებელია:** დემო შესვლა ნაგულისხმევად ჩართულია (S-01) — დაყენებაზე ერთი გამოტოვებული ცვლადი და ნებისმიერი ადმინია.
- **ახლავე გასასწორებელი:** open redirect ოთხ ადგილას (S-02).
- **პროცესი:** რეალური მონაცემის გადაცემის წესი არ არის (S-03). AI აგენტები — მხოლოდ დემო ბაზაზე (ლუკას გადაწყვეტილება, Q-01).
- **კოორდინატორი** ლუკას გადაწყვეტილებას არ შეესაბამება (S-14).
- სულ: 1 კრიტიკული, 4 მნიშვნელოვანი, 9 წვრილმანი; 3 კითხვა — სამივეს პასუხი აქვს.

## შემოწმდა, პრობლემა არ არის

- **CSRF:** 26-ვე POST route `same_origin()`-ს იძახებს; cookie — `httponly`, `samesite=lax`.
- **უფლებები:** 58 route-იდან 49-ს `current` / `require(...)` / `ADMIN` აქვს; დანარჩენი 9 — შესვლა / გასვლა, `/api/health`,
  `/qc/disputes` (მხოლოდ გადამისამართება) და `/role` (სესიას თავად კითხულობს — S-10); ადმინის გვერდები — `Depends(ADMIN)`;
  მეილის ნახვა — ოპერატორს მხოლოდ თავისი, CSP-ით; Pre-QC — `_guard`; შეზღუდული სტატისტიკა — `can_see_restricted_stats`.
- **ხილვადობა:** ოქმი, ფაილი, presence, `/api/items*` — `scope.can_view` / `items_query`; სხვისი ჩანაწერი → 404.
- **ქმედება სერვერზე:** `workflow.apply` → `available_actions` (როლი + მდგომარეობა); ფაილის ატვირთვა — მხოლოდ QC როლებს.
- **XSS:** Jinja autoescape; `|safe` მხოლოდ ხატულების სტატიკურ SVG-ზე; `tojson_attr` `<`-ს ანიღბავს; JS-ში მონაცემი `innerHTML`-ში ყველგან `esc()`-ით (`app.js`, `stats.js`, `stats-tabler-preview.js`).
- **SQL:** ყველგან ORM; raw SQL მხოლოდ `distribution/source.py`-ში — `?` პარამეტრებით და `mode=ro` კავშირით.
- **ფაილები:** ზომა 10 MB, ტიპების სია, სახელს სერვერი ქმნის (uuid), ბრუნდება შენახული ტიპით + `nosniff`; გზა ბაზიდან, არა მომხმარებლისგან.
- **სესია:** სერვერზე, გაუქმებადი, 12 სთ; გამორთული მომხმარებელი მაშინვე გადის; როლი ყოველ მოთხოვნაზე თავიდან მოწმდება.
- **Google:** state, nonce, PKCE, iss / aud / exp / email_verified, `hd`; მხოლოდ რეგისტრირებული ელფოსტა.
- **საიდუმლოებები და git:** კოდში პაროლი / token არ არის; მთელ ისტორიაში `data/`, `*.db`, `*.xlsx`, `*.sqlite`, `.env` არასოდეს მოხვედრილა.
- **გარე რესურსი:** შაბლონებსა და `static/`-ში CDN, გარე ფონტი ან სკრიპტი არ არის.
- **თავსართები:** `nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy`, `no-store` — `/api/`, `/items/`.
- **პირადი ნომერი:** მხოლოდ ადმინის მომხმარებლის გვერდზე, `|mask_pid`-ით; `User.__repr__` მას არ ბეჭდავს.
