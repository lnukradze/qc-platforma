## 2. ლუკას გადაწყვეტილებები (2026-10-27) — მოკლედ

სრული ტექსტი — `docs/OPEN_QUESTIONS.md`.

- „ორივე მართალია“ → დადებითი, ოპერატორის ხარვეზი **არა**; „ველი მართალია“ → დადებითი + ოპერატორის ხარვეზი. ხელახლა შეცვლისას ნიშნები ბოლო გადაწყვეტილებას მიჰყვება.
- ველი ხედავს ყველა ოქმს, რომელზეც კითხვა მიიღო; დასრულებული — მხოლოდ ფილტრით / ძებნით.
- ველის პასუხები: უარყოფითი — შესწორდა / არ ვეთანხმები; რეკომენდაცია — სამივე; დაზუსტება — მხოლოდ კომენტარი.
- პასუხის დრო: პირველი გაგზავნა → პირველი პასუხი.
- სტატუსის შეცვლის მოთხოვნისას ოქმი ველს არ უჩანს, სანამ QC მენეჯერი არ გადაწყვეტს.
- ველის სტატისტიკაში ოპერატორები სახელით არსად; შესვლის სია — მხოლოდ ტესტირებისთვის.
- `Ctrl+K` — მოიხსნა; `--*-ink` ტოკენები; `style="--w: N%"` — გამონაკლისი; ყველა აგენტი — ერთ დემო ვერსიაზე.
