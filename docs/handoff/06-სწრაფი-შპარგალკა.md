## 5. მდგომარეობები ✅

`pending` (გასავლელი) → `awaiting_field` (ველზე) → `awaiting_manager` („არ ვეთანხმები“, მენეჯერი) → `awaiting_qcm` (არ დათანხმებული, QC მენეჯერი) → `returned_to_manager` (დაბრუნებულია მენეჯერთან) → `awaiting_qc` (გადასამოწმებელი) → `closed`.

**დახურვის მიზეზი:** `positive` · `corrected` (M) · `acknowledged` · `qc_error` (ველი მართალია) · `both_right`.
**ვერდიქტი:** დადებითი · უარყოფითი · რეკომენდაცია · დაზუსტება (კითხვაა, არა სტატუსი).
**D (`checked_at`)** = სტატუსის პირველი გაგზავნა; არ იცვლება. **დღის რაოდენობა** = `first_sent_at` (დაზუსტების ჩათვლით).

## 8. IT-სგან — პილოტის მინიმუმი (P1)

1. **VM** (R1) — 💡 4 vCPU / 8 GB / 100 GB;
2. **OS / runtime** (R2) — Linux ან Windows, Python ≥ 3.12 ან Docker; შიდა root CA;
3. **PostgreSQL** (R3) — ცალკე ბაზა, `qc_app` + `qc_migrator`, superuser-ის გარეშე;
4. **ბექაპი** (R4) — ღამის; P3-ში PITR;
5. **ფაილების საცავი + ბექაპი** (R5);
6. **დომენი + DNS** (R6), **სერტიფიკატი** (R7);
7. **Reverse proxy** (R8) — ≥ 12 MB, `X-Forwarded-*`, ლოგი query string-ის გარეშე;
8. **შიდა წვდომა** (R9);
9. **გამავალი** `oauth2.googleapis.com:443` (R11);
10. **Google OAuth client** — Web, redirect `https://<დომენი>/auth/google/callback`, scope `openid email profile` (R12);
11. **საიდუმლოების შენახვა** (R19);
12. **git + deployment** (R22);
13. **NTP + Asia/Tbilisi** (R24);
14. **RACI** (R25).
