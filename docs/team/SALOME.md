# სალომე — სამი აგენტი ერთად: გზამკვლევი

შენ მართავ სამ აგენტს: ორ Claude-ს და Codex-ს. ამოცანებს ლუკა (lead) წერს; შენ აგენტებს გადასცემ, შედეგს უყურებ
და ლუკას ეუბნები, როცა რამე ჩასაბარებელია. ყველა აგენტი ქართულად გელაპარაკება.

## ვინ ვინ არის

| ტერმინალი | აგენტი | როლი | რას აკეთებს |
|---|---|---|---|
| **ui** | შენი Claude (`salome-1`) | აწყობა | გვერდები და დიზაინი (HTML, CSS, JS) |
| **backend** | შენი მეორე Claude (`salome-2`) | ფუნქციონალი და თავსებადობა | Python-ის ლოგიკა; ტელეფონი, ბრაუზერები, PostgreSQL, API |
| **qa** | შენი Codex | ლუკას მარჯვენა ხელი | ლუკას ამოცანას დეტალურ პრომპტად აქცევს; ამოწმებს შედეგს (მეორე ტესტერი) |

თითოეული ცალკე საქაღალდეში მუშაობს (`qc-platforma-ui`, `-backend`, `-qa`), ამიტომ ერთმანეთის ფაილებს ვერ გადაწერენ.

## ერთხელ

1. **განახლება.** VS Code-ში გახსენი `qc-platforma` → Terminal → New Terminal → `git pull`.
   რეპო ჯერ არ გაქვს? → `QC-setup-salome.md`, ნაბიჯი 6-დან (ის შენი Claude-ის ჩატში ჩააგდე).
2. **Node.js (არასავალდებულო)** — Codex-ს Hallmark-ის დიზაინის შემოწმებისთვის სჭირდება. შენს Claude-ს (VS Code-ის პანელში) მიეცი:
   > დააყენე Node.js LTS პორტატულად, ადმინის უფლების გარეშე: nodejs.org-დან Windows x64 zip, ამოარქივე
   > `%LOCALAPPDATA%\Programs\node`-ში, დაამატე მომხმარებლის PATH-ში და შეამოწმე `node --version`.

   ამის შემდეგ VS Code მთლიანად დახურე და თავიდან გახსენი.

## ყოველდღე — სამივეს გაშვება ერთად

**VS Code → Terminal → Run Task… → „სალომე: სამივე აგენტი“.**

- ერთად გაიხსნება სამი ტერმინალი: ui, backend, qa. ყოველი აგენტი თვითონ კითხულობს თავის როლს და ამოცანებს
  და ქართულად გეტყვის, რა აქვს გასაკეთებელი.
- ტერმინალებს შორის გადასვლა — ტერმინალის პანელის მარჯვნივ, სიაში. გვერდიგვერდ რომ ნახო — ჩანართი გადაათრიე.
- **პირველ გაშვებაზე (ერთხელ):**
  - ui → `/login` → Claude ანგარიში **#1**;
  - backend → `/login` → Claude ანგარიში **#2** — შესვლის ბმული დააკოპირე და გახსენი **InPrivate** ფანჯარაში (`Ctrl+Shift+N`),
    თორემ ბრაუზერი ანგარიშ #1-ს აირჩევს;
  - qa → Sign in with ChatGPT.
- ცალკე გაშვება: იგივე მენიუ → „აგენტი: ui …“, „აგენტი: backend …“ ან „აგენტი: qa — Codex“.

## ეტაპი 2 — ლუკას ცვლილებები და აუდიტის გასწორებები (2026-10-27-დან)

**ერთხელ, დაწყებამდე:**
1. სამივე ტერმინალში `git pull` (ან აგენტს — `git fetch`), შემდეგ სამივე დახურე და თავიდან გაუშვი („სალომე: სამივე აგენტი“).

## თუ რამე არ გამოვიდა

- **Run Task-ში „სალომე: სამივე აგენტი“ არ ჩანს** → `git pull`; VS Code-ში გახსნილი უნდა იყოს სწორედ `qc-platforma` საქაღალდე.
- **„codex not found“** → VS Code-ში დააყენე Codex (OpenAI) გაფართოება. ან: File → Open Folder → `qc-platforma-qa` → Codex-ის პანელში:
  `შენი როლია qa — წაიკითხე AGENTS.md და docs/team/roles/qa.md`.
- **push უარყოფილია (rejected)** → აგენტს: `git pull --rebase origin main და ისევ ატვირთე`.
- **ორივე Claude ერთი ანგარიშით შევიდა** → backend ტერმინალში `/logout`, შემდეგ `/login` და ბმული InPrivate ფანჯარაში.
- **სხვა რამე** → შეცდომის ტექსტი ლუკას გაუგზავნე.
